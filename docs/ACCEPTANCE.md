# Linux 26.60 acceptance checklist

Use a test world with Endstone 0.11.15 and the exact Linux BDS 1.26.60.6 package. Keep the current configuration, generated pack, and `jukeboxes.json` when updating the plugin. This checklist requires an actual Bedrock 26.60 client; automated packet tests cannot prove audible playback.

1. Install the 0.2.1 wheel and start the server. `/cmusic status` must report runtime 26.60, protocol 2225, Endstone 0.11.15, and `adapter supported=True`. No converter download should occur during plugin enable.
2. Put two audio files with distinct names in `plugins/music/uploads/`. Set `target_world_name` to the test world and run `/cmusic generate`. Normal gameplay should continue while the background job converts them. Source uploads must remain intact.
3. Restart the server and reconnect the client, accepting/downloading the generated resource pack. Confirm the generated pack's version matches its `world_resource_packs.json` entry.
4. Open `/cmusic` → **Albums & Discs** → **Create album / single-track disc**. Create one disc with a single track ID and another with two ordered IDs (`custom.<normalized_filename>`). Select each saved disc in the menu to receive the corresponding item, or run `/cmusic give <id> [player name]`.
5. Right-click an empty jukebox with a custom disc. Exactly one item must leave the hand. Nearby players in the same dimension should hear one stream. The second album track should start after the first track's measured duration, adjusted for pitch.
6. With Follow Player enabled (the default), start listening near the jukebox and walk far enough to unload its chunk. The volume must remain constant, with no movement-triggered restarts, and the entire remaining album must finish. A second player outside the initial radius must not receive the music; entering range while the box is available should join the current song at its current offset. `/cmusic status` should show adapted packets and zero rejected layouts. If the packet layout is rejected or seeking is wrong, record the status and server/client versions; do not treat the adapter as qualified.
7. Walk past a second jukebox: it must not interrupt the pushed album. Explicitly insert or skip/restart a disc on that jukebox to choose it instead. Travel to the Nether and back: an already attached listener should continue at the current album offset, while other players there must not receive it. Disable Follow Player on a test preset and repeat: positional mode should fade/cut off outside its radius, select the nearest audible jukebox, and remain dimension-limited.
8. Normal right-click on an occupied custom jukebox ejects the exact stored disc. Sneak-right-click skips a track, or restarts a finished playlist. A full inventory must keep the disc inserted and prevent breaking the block until it can be returned.
9. Create a second jukebox preset through **Custom Jukebox Setup**, run `/cmusic generate`, restart, then bind it to an individual matching block with `/cmusic bind <preset>`. Verify that each block uses its selected radius/volume/pitch. New block models must already be registered by their behavior/resource pack.
10. Restart with a disc inserted. Its inventory item must remain stored and ejectable, and its playlist should restart from the beginning. If the block was externally removed, `/cmusic recover` must return the stored item once. Filesystem persistence and the game's player inventory are separate stores; a process crash during a transfer still requires an inventory audit.
11. Configure a personal join sound, reconnect, then activate another personal track. The join sound must play once, and its old duration must not stop the newer track or other game audio. Disconnect/reconnect quickly to verify that an old join callback is not applied to the new session.
12. Run `/cmusic stop`, then disable the plugin. Only plugin-owned sound IDs should be stopped. The inserted discs must remain recoverable. Confirm clean shutdown.

Record Linux distribution, Python version, BDS executable SHA-256, Endstone version, client version, pack UUID/version, status counters, and the result of each item. Never mark `audible_playback_verified` true from a unit test or an empty-server startup alone.

Also verify retained operator global playlists and generated custom playlist items/blocks: /cmusic playlists, play, next, stop and give jukebox; playlist editing, dimension-specific binding, permission revocation with an open menu, and late joining at the current track position. Global playback must take priority over legacy triggers and join sounds. Regenerate both packs after upgrading from 0.2.0.
